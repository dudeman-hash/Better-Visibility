# Zoom Out Vision

Zoom Out Vision applies a configurable multiplier to Geometry Dash's gameplay camera zoom so you can see more of the level ahead.

Open the mod's settings in Geode and adjust **Zoom-out multiplier**. `1.0` disables the effect; larger values zoom farther out. The initial value is `1.25` and the range is `1.0`–`2.0`.

This mod affects the view, not player physics, hitboxes, or level data. It overrides camera zoom values from level zoom triggers while active.

**Target:** Geode v1.5.5, Geometry Dash iOS 2.2081. Source-only archive; compile to an iOS `.geode` package before installing.
